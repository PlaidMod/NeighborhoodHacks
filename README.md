# ShowUp HTX

Type your address and see every local government that affects you (school board, city council, commissioners court, flood control, and your utility district), what each one is deciding next, and how to be heard.

- **Live demo:** https://showup-htx.vercel.app
- **App code:** [`web/`](web/) (Next.js, Tailwind, shadcn/ui)
- **Design system and contribution rules:** [`web/DESIGN.md`](web/DESIGN.md). Read it before you change any UI.

## Run locally

```bash
cd web && npm install && npm run dev
```

Meeting and agenda data is sample data for the prototype. District lookup is approximate by ZIP code.
